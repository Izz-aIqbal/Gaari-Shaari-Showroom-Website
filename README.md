# Gaari-Shaari-Showroom-Website | Car Showroom Management System

A complete web-based application designed to streamline car showroom operations, inventory management, user orders, and administrative tasks in real-time.

---

##  Project Overview

**Gaari-Shaari** provides an intuitive digital solution for modern car showrooms. It optimizes customer experience through seamless vehicle browsing and order tracking while empowering administrators with inventory, user management, and order monitoring tools.

---

##  Features & Capabilities

###  User Portal
* **Secure Authentication**: User sign-up, login, and session management via PHP.
* **Interactive Catalog**: Browse featured models (e.g., BMW, Mercedes) with detailed specifications and pricing.
* **Order Management**: Effortless order placement and status tracking.

###  Admin Dashboard
* **Inventory Control**: Real-time CRUD operations to add, update, or remove car listings.
* **Order Monitoring**: Track, process, and fulfill customer orders efficiently.
* **User Management**: Monitor user activities and manage profile records.

---

##  Tech Stack & Architecture

| Layer | Technologies | Role & Functionality |
| :--- | :--- | :--- |
| **Frontend** | HTML5, CSS3 | Clean, responsive design adapted across mobile and desktop interfaces. |
| **Backend** | PHP | Core business logic, authentication routines, and API endpoints. |
